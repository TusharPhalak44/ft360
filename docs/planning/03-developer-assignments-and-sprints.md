# Module-Wise Team Allocation & Deliverable Ownership

**Last Updated:** 2026-11-12  
**Status:** Approved Vertical Deliverable Model (Phase 1 Active)  
**Version:** 0.2.0

> **Allocation Principle:** Work is **never** split horizontally into "frontend-only" vs "backend-only" silos. Each engineer (Tushar, Nakshatra, Mansi) owns **complete vertical deliverables and modules end-to-end**—spanning SQL schema/migrations, NestJS repositories/services/controllers, Next.js UI workflows, documentation, and automated unit/integration/E2E tests.
